# كامب ساس · CAMP SAS

تطبيق لمدير المخيم (Camp Boss) لإدارة السكن: الغرف وأقسامها (10/1، 10/2…)، الشفتات (3 أسرّة لكل شفت، ويمكن إضافة شفت ثالث ورابع)، الساكنون (الاسم، الرقم الوظيفي، الهاتف، الشركة)، والبلاغات حتى تنفيذها.

- **صفحة الويب:** تفتح من الرابط على الجوال أو الكمبيوتر، وتعمل بدون إنترنت، وتُضاف إلى الشاشة الرئيسية من Safari ← مشاركة ← «إضافة إلى الشاشة الرئيسية».
- **أندرويد (APK) والآيفون (IPA):** تُبنى تلقائياً على GitHub Actions مع كل تحديث وتظهر في قسم Releases. الـIPA بدون توقيع: وقّعه بتطبيق التوقيع ثم ثبّته. فيهما تنبيهات البلاغات على شاشة القفل حتى والتطبيق مغلق، مع زر «تم التنفيذ ✓» داخل التنبيه.
- العربية والإنجليزية، الوضع النهاري والليلي والتلقائي، خط المراعي.
- التصدير: Excel أو PDF أو صور PNG / ZIP بدقة عالية، لكل الغرف أو غرفة معيّنة أو غرف تختارها.
- البيانات محفوظة في الجهاز، مع نسخة احتياطية واسترجاع من الإعدادات.

الإصدار الحالي: **v1.0**
